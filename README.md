\# Hand Gesture Controller



A Python-based hand gesture controller that uses a webcam and MediaPipe to recognize hand gestures and control computer media actions.



\## Features



\- Real-time hand detection

\- 21 hand landmarks

\- Finger detection

\- Gesture recognition

\- Media control using hand gestures

\- Webcam-based interaction

\- Python + OpenCV + MediaPipe



\## Gesture Controls



| Gesture | Action |

|---|---|

| 👊 Fist | Stop |

| ☝️ One | Next Track |

| ✌️ Two | Play / Pause |

| 👍 Thumb | Volume Up |

| 🖐️ Open Hand | Mute |



\## Technologies



\- Python

\- OpenCV

\- MediaPipe

\- PyAutoGUI
